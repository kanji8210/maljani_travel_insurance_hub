# Maljani Travel Insurance Hub

Maljani Travel Insurance Hub is a comprehensive WordPress plugin designed to streamline the sales and management of travel insurance policies. It integrates with various insurer APIs, provides a modern "Quote Wizard" for users, and includes robust administrative tools for agencies and moderators.

## Key Features

- **Quote Wizard**: A premium, multi-step interface for users to get travel insurance quotes with glassmorphism styling and smooth transitions.
- **Insurer API Integration**: A modular engine that communicates with different insurer backend systems using specialized adapters.
- **Sales Moderation**: A dashboard for admins and agencies to track sales, manage commissions, and handle policy issuance.
- **Agency Management**: Specialized tools for agencies to track their sales and commissions.
- **Live Chat**: An integrated chat system for real-time customer support.
- **Project Memory**: Built-in institutional knowledge tracking (bugs, decisions, key facts).

## Project Structure

- `admin/`: Administrative interfaces and logic (Moderators, Agencies, Users).
- `includes/`: Core functionality, API engines, and database tools.
- `public/`: User-facing assets and logic.
- `templates/`: WordPress template overrides for policies and profiles.
- `docs/`: Technical documentation and project notes.
- `.agents/skills/`: Modular agentic AI capabilities (Design, Memory, Documentation).

## Technical Requirements

- **PHP**: 7.4+
- **WordPress**: 5.8+
- **Database**: MySQL 5.7+ / MariaDB 10.2+
